# Depviz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `dev.gois.tools:depviz-maven-plugin` Maven plugin that generates an offline React/shadcn/Cytoscape dependency graph viewer from Maven project dependency data.

**Architecture:** The Maven plugin stays Java-first and delegates to focused services for config, extraction, graph construction, output writing, and browser opening. The viewer is developed under `viewer/` with React, Vite, shadcn/ui-style components, and Cytoscape; the Maven build compiles it into static assets packaged in the plugin JAR and copied to `target/depviz/` at runtime.

**Tech Stack:** Java 17, Maven 3.9+, Maven Plugin Tools, Maven Shared Dependency Tree, Jackson, JUnit 5, AssertJ, Maven Invoker Plugin, npm, Vite, React, TypeScript, shadcn/ui, Cytoscape.js, Vitest.

package dev.gois.tools.depviz.config;

import java.util.Locale;

public enum DepvizScope {
    COMPILE("compile"),
    RUNTIME("runtime"),
    TEST("test"),
    PROVIDED("provided"),
    SYSTEM("system"),
    IMPORT("import"),
    ALL("all");

    private final String value;

    DepvizScope(String value) {
        this.value = value;
    }

    public String value() {
        return value;
    }

    public static DepvizScope parse(String raw) {
        String normalized = raw == null || raw.isBlank() ? "runtime" : raw.trim().toLowerCase(Locale.ROOT);
        for (DepvizScope scope : values()) {
            if (scope.value.equals(normalized)) {
                return scope;
            }
        }
        throw new IllegalArgumentException("Invalid depviz.scope '" + raw + "'. Accepted values: compile, runtime, test, provided, system, import, all.");
    }

    public boolean includesDependencyScope(String dependencyScope) {
        if (this == ALL) {
            return true;
        }
        if (dependencyScope == null || dependencyScope.isBlank()) {
            return this == COMPILE || this == RUNTIME;
        }
        String normalized = dependencyScope.toLowerCase(Locale.ROOT);
        return switch (this) {
            case COMPILE -> normalized.equals("compile") || normalized.isBlank();
            case RUNTIME -> normalized.equals("compile") || normalized.equals("runtime") || normalized.isBlank();
            case TEST -> true;
            case PROVIDED -> normalized.equals("provided");
            case SYSTEM -> normalized.equals("system");
            case IMPORT -> normalized.equals("import");
            case ALL -> true;
        };
    }
}

package dev.gois.tools.depviz.config;

import java.nio.file.Path;

public record DepvizConfig(
    DepvizScope scope,
    boolean open,
    String includes,
    String excludes,
    DepvizLayout initialLayout,
    NodeMode nodeMode,
    int maxInitialLabels,
    Path outputDirectory
) {
    public static DepvizConfig fromRaw(
        String scope,
        String open,
        String includes,
        String layout,
        String nodeMode,
        String maxInitialLabels,
        String excludes,
        Path outputDirectory
    ) {
        DepvizScope parsedScope = DepvizScope.parse(scope);
        DepvizLayout parsedLayout = DepvizLayout.parse(layout);
        NodeMode parsedNodeMode = NodeMode.parse(nodeMode);
        boolean parsedOpen = open == null || open.isBlank() || Boolean.parseBoolean(open);
        int parsedMaxInitialLabels = parseMaxInitialLabels(maxInitialLabels);
        Path resolvedOutputDirectory = outputDirectory == null ? Path.of("target", "depviz") : outputDirectory;
        return new DepvizConfig(
            parsedScope,
            parsedOpen,
            blankToNull(includes),
            blankToNull(excludes),
            parsedLayout,
            parsedNodeMode,
            parsedMaxInitialLabels,
            resolvedOutputDirectory
        );
    }

    private static int parseMaxInitialLabels(String raw) {
        if (raw == null || raw.isBlank()) {
            return 500;
        }
        try {
            int value = Integer.parseInt(raw.trim());
            if (value <= 0) {
                throw new IllegalArgumentException("depviz.maxInitialLabels must be greater than zero.");
            }
            return value;
        } catch (NumberFormatException exception) {
            throw new IllegalArgumentException("depviz.maxInitialLabels must be an integer.", exception);
        }
    }

    private static String blankToNull(String raw) {
        return raw == null || raw.isBlank() ? null : raw.trim();
    }
}

package dev.gois.tools.depviz.util;

import dev.gois.tools.depviz.graph.ArtifactCoordinate;
import java.util.Arrays;
import java.util.List;

public record PatternMatcher(String groupId, String artifactId, String type, String version) {
    public static List<PatternMatcher> parseList(String raw) {
        if (raw == null || raw.isBlank()) {
            return List.of();
        }
        return Arrays.stream(raw.split(","))
            .map(String::trim)
            .filter(value -> !value.isEmpty())
            .map(PatternMatcher::parse)
            .toList();
    }

    public static PatternMatcher parse(String raw) {
        String[] parts = raw == null ? new String[0] : raw.trim().split(":", -1);
        if (parts.length != 2 && parts.length != 4) {
            throw new IllegalArgumentException(
                "Invalid dependency pattern '" + raw + "'. Use groupId:artifactId or groupId:artifactId:type:version."
            );
        }
        return new PatternMatcher(
            normalize(parts[0]),
            normalize(parts[1]),
            parts.length == 4 ? normalize(parts[2]) : "*",
            parts.length == 4 ? normalize(parts[3]) : "*"
        );
    }

    public boolean matches(ArtifactCoordinate coordinate) {
        return segmentMatches(groupId, coordinate.groupId())
            && segmentMatches(artifactId, coordinate.artifactId())
            && segmentMatches(type, coordinate.type())
            && segmentMatches(version, coordinate.version());
    }

    private static String normalize(String value) {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException("Invalid dependency pattern segment.");
        }
        return value.trim();
    }

    private static boolean segmentMatches(String pattern, String value) {
        return "*".equals(pattern) || pattern.equals(value);
    }
}

package dev.gois.tools.depviz.graph;

import dev.gois.tools.depviz.config.DepvizConfig;
import dev.gois.tools.depviz.util.Coordinates;
import java.time.Instant;
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashMap;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

public final class GraphDocumentBuilder {
    public GraphDocument build(ExtractedDependencyNode root, ProjectInfo projectInfo, DepvizConfig config) {
        Map<String, GraphNodeAccumulator> nodes = new LinkedHashMap<>();
        Map<String, GraphEdge> edges = new LinkedHashMap<>();
        List<GraphPath> paths = new ArrayList<>();
        List<DiagnosticEntry> diagnostics = new ArrayList<>();

        traverse(root, null, 0, new ArrayDeque<>(), nodes, edges, paths, diagnostics);

        List<GraphNode> graphNodes = nodes.values().stream()
            .map(GraphNodeAccumulator::toNode)
            .sorted(Comparator.comparingInt(GraphNode::depth).thenComparing(GraphNode::id))
            .toList();
        List<GraphEdge> graphEdges = new ArrayList<>(edges.values());
        GraphSummary summary = summarize(graphNodes, graphEdges);
        ViewerConfig viewerConfig = new ViewerConfig(
            config.initialLayout().value(),
            config.maxInitialLabels(),
            config.nodeMode().value()
        );

        return new GraphDocument(
            "1",
            Instant.now(),
            projectInfo,
            summary,
            viewerConfig,
            graphNodes,
            graphEdges,
            paths,
            diagnostics
        );
    }

    private void traverse(
        ExtractedDependencyNode current,
        ExtractedDependencyNode parent,
        int depth,
        ArrayDeque<String> path,
        Map<String, GraphNodeAccumulator> nodes,
        Map<String, GraphEdge> edges,
        List<GraphPath> paths,
        List<DiagnosticEntry> diagnostics
    ) {
        String currentId = Coordinates.stableId(current.coordinate());
        nodes.compute(currentId, (id, existing) -> {
            GraphNodeAccumulator accumulator = existing == null
                ? GraphNodeAccumulator.from(current, id, depth)
                : existing;
            accumulator.minimumDepth = Math.min(accumulator.minimumDepth, depth);
            accumulator.root = accumulator.root || parent == null;
            return accumulator;
        });
        diagnostics.addAll(current.diagnostics());

        if (parent != null) {
            String parentId = Coordinates.stableId(parent.coordinate());
            String edgeId = parentId + " -> " + currentId;
            edges.putIfAbsent(edgeId, new GraphEdge(edgeId, parentId, currentId, current.scope(), current.optional(), depth));
        }

        path.addLast(currentId);
        paths.add(new GraphPath(currentId, List.copyOf(path)));
        for (ExtractedDependencyNode child : current.children()) {
            traverse(child, current, depth + 1, path, nodes, edges, paths, diagnostics);
        }
        path.removeLast();
    }

    private GraphSummary summarize(List<GraphNode> nodes, List<GraphEdge> edges) {
        Map<String, Integer> byScope = new HashMap<>();
        Map<String, Integer> byGroup = new HashMap<>();
        for (GraphNode node : nodes) {
            byScope.merge(node.scope(), 1, Integer::sum);
            byGroup.merge(node.groupId(), 1, Integer::sum);
        }
        return new GraphSummary(nodes.size(), edges.size(), byScope, byGroup);
    }

    private static final class GraphNodeAccumulator {
        private final ExtractedDependencyNode source;
        private final String id;
        private int minimumDepth;
        private boolean root;
        private final Set<String> scopes = new LinkedHashSet<>();

        private GraphNodeAccumulator(ExtractedDependencyNode source, String id, int minimumDepth) {
            this.source = source;
            this.id = id;
            this.minimumDepth = minimumDepth;
            this.root = minimumDepth == 0;
            this.scopes.add(scopeOrRoot(source.scope(), minimumDepth));
        }

        static GraphNodeAccumulator from(ExtractedDependencyNode source, String id, int minimumDepth) {
            return new GraphNodeAccumulator(source, id, minimumDepth);
        }

        GraphNode toNode() {
            ArtifactCoordinate coordinate = source.coordinate();
            String scope = root ? "root" : scopes.iterator().next();
            return new GraphNode(
                id,
                coordinate.groupId(),
                coordinate.artifactId(),
                coordinate.version(),
                coordinate.type(),
                coordinate.classifier(),
                scope,
                source.optional(),
                minimumDepth,
                root,
                false,
                Coordinates.label(coordinate),
                Coordinates.displayCoordinate(coordinate),
                coordinate.groupId()
            );
        }

        private static String scopeOrRoot(String scope, int depth) {
            if (depth == 0) {
                return "root";
            }
            return scope == null || scope.isBlank() ? "compile" : scope;
        }
    }
}

package dev.gois.tools.depviz.graph;

import dev.gois.tools.depviz.config.DepvizScope;
import dev.gois.tools.depviz.util.PatternMatcher;
import java.util.ArrayList;
import java.util.List;

public final class GraphFilters {
    private GraphFilters() {
    }

    public static ExtractedDependencyNode apply(
        ExtractedDependencyNode root,
        DepvizScope scope,
        List<PatternMatcher> includes,
        List<PatternMatcher> excludes
    ) {
        ExtractedDependencyNode scopeFiltered = filterByScope(root, scope, true);
        if (scopeFiltered == null) {
            return root;
        }
        ExtractedDependencyNode excluded = filterExcludes(scopeFiltered, excludes, true);
        if (excluded == null) {
            return root;
        }
        if (includes == null || includes.isEmpty()) {
            return excluded;
        }
        ExtractedDependencyNode included = filterIncludes(excluded, includes, true);
        return included == null ? copyWithChildren(excluded, List.of()) : included;
    }

    private static ExtractedDependencyNode filterByScope(ExtractedDependencyNode node, DepvizScope scope, boolean root) {
        List<ExtractedDependencyNode> children = new ArrayList<>();
        for (ExtractedDependencyNode child : node.children()) {
            ExtractedDependencyNode filtered = filterByScope(child, scope, false);
            if (filtered != null) {
                children.add(filtered);
            }
        }
        if (!root && !scope.includesDependencyScope(node.scope())) {
            return null;
        }
        return copyWithChildren(node, children);
    }

    private static ExtractedDependencyNode filterExcludes(ExtractedDependencyNode node, List<PatternMatcher> excludes, boolean root) {
        if (!root && matchesAny(excludes, node.coordinate())) {
            return null;
        }
        List<ExtractedDependencyNode> children = new ArrayList<>();
        for (ExtractedDependencyNode child : node.children()) {
            ExtractedDependencyNode filtered = filterExcludes(child, excludes, false);
            if (filtered != null) {
                children.add(filtered);
            }
        }
        return copyWithChildren(node, children);
    }

    private static ExtractedDependencyNode filterIncludes(ExtractedDependencyNode node, List<PatternMatcher> includes, boolean root) {
        List<ExtractedDependencyNode> children = new ArrayList<>();
        for (ExtractedDependencyNode child : node.children()) {
            ExtractedDependencyNode filtered = filterIncludes(child, includes, false);
            if (filtered != null) {
                children.add(filtered);
            }
        }
        if (root || matchesAny(includes, node.coordinate()) || !children.isEmpty()) {
            return copyWithChildren(node, children);
        }
        return null;
    }

    private static boolean matchesAny(List<PatternMatcher> patterns, ArtifactCoordinate coordinate) {
        if (patterns == null || patterns.isEmpty()) {
            return false;
        }
        return patterns.stream().anyMatch(pattern -> pattern.matches(coordinate));
    }

    private static ExtractedDependencyNode copyWithChildren(ExtractedDependencyNode node, List<ExtractedDependencyNode> children) {
        return new ExtractedDependencyNode(node.coordinate(), node.scope(), node.optional(), children, node.diagnostics());
    }
}

package dev.gois.tools.depviz.output;

import java.awt.Desktop;
import java.net.URI;

public final class BrowserOpener {
    private final boolean desktopAllowed;

    public BrowserOpener() {
        this(true);
    }

    BrowserOpener(boolean desktopAllowed) {
        this.desktopAllowed = desktopAllowed;
    }

    public boolean open(URI uri) {
        if (!desktopAllowed || !Desktop.isDesktopSupported()) {
            return false;
        }
        try {
            Desktop desktop = Desktop.getDesktop();
            if (!desktop.isSupported(Desktop.Action.BROWSE)) {
                return false;
            }
            desktop.browse(uri);
            return true;
        } catch (RuntimeException | java.io.IOException exception) {
            return false;
        }
    }
}

package dev.gois.tools.depviz.output;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.SerializationFeature;
import com.fasterxml.jackson.datatype.jsr310.JavaTimeModule;
import dev.gois.tools.depviz.graph.GraphDocument;
import dev.gois.tools.depviz.util.JsonEscaper;
import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public final class ViewerWriter {
    private final ObjectMapper objectMapper;

    public ViewerWriter() {
        this.objectMapper = new ObjectMapper()
            .registerModule(new JavaTimeModule())
            .enable(SerializationFeature.INDENT_OUTPUT)
            .disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);
    }

    public OutputFiles write(GraphDocument document, Path outputDirectory) throws IOException {
        Files.createDirectories(outputDirectory);
        Path assetsDirectory = outputDirectory.resolve("assets");
        Files.createDirectories(assetsDirectory);

        Path jsonFile = outputDirectory.resolve("dependency-graph.json");
        String json = objectMapper.writeValueAsString(document);
        Files.writeString(jsonFile, json, StandardCharsets.UTF_8);

        copyAsset("app.js", assetsDirectory);
        copyAsset("style.css", assetsDirectory);
        copyAsset("LICENSES.txt", assetsDirectory);

        String template = loadResource("dependency-graph.html.tpl");
        String html = template
            .replace("__GRAPH_JSON__", JsonEscaper.forInlineScript(json))
            .replace("__ASSET_PREFIX__", "assets");
        Path htmlFile = outputDirectory.resolve("dependency-graph.html");
        Files.writeString(htmlFile, html, StandardCharsets.UTF_8);
        return new OutputFiles(outputDirectory, htmlFile, jsonFile);
    }

    private void copyAsset(String name, Path assetsDirectory) throws IOException {
        Files.write(assetsDirectory.resolve(name), loadResourceBytes("assets/" + name));
    }

    private String loadResource(String name) throws IOException {
        return new String(loadResourceBytes(name), StandardCharsets.UTF_8);
    }

    private byte[] loadResourceBytes(String name) throws IOException {
        String path = "/depviz/" + name;
        try (InputStream stream = ViewerWriter.class.getResourceAsStream(path)) {
            if (stream == null) {
                throw new IOException("Resource not found: " + path);
            }
            return stream.readAllBytes();
        }
    }
}

```java
package dev.gois.tools.depviz.graph;

import dev.gois.tools.depviz.config.DepvizConfig;
import java.util.List;
import org.apache.maven.artifact.Artifact;
import org.apache.maven.plugin.MojoExecutionException;
import org.apache.maven.project.MavenProject;
import org.apache.maven.shared.dependency.graph.DependencyGraphBuilder;
import org.apache.maven.shared.dependency.graph.DependencyGraphBuilderException;
import org.apache.maven.shared.dependency.graph.DependencyNode;

public final class MavenDependencyGraphExtractor implements DependencyGraphExtractor {
    private final DependencyGraphBuilder dependencyGraphBuilder;

    public MavenDependencyGraphExtractor(DependencyGraphBuilder dependencyGraphBuilder) {
        this.dependencyGraphBuilder = dependencyGraphBuilder;
    }

    @Override
    public ExtractedDependencyNode extract(MavenProject project, DepvizConfig config) throws MojoExecutionException {
        try {
            DependencyNode dependencyRoot = dependencyGraphBuilder.buildDependencyGraph(project, null);
            ExtractedDependencyNode root = convertProjectRoot(project, dependencyRoot);
            return GraphFilters.apply(root, config.scope(), dev.gois.tools.depviz.util.PatternMatcher.parseList(config.includes()), dev.gois.tools.depviz.util.PatternMatcher.parseList(config.excludes()));
        } catch (DependencyGraphBuilderException | IllegalArgumentException exception) {
            throw new MojoExecutionException("Failed to resolve Maven dependency graph: " + exception.getMessage(), exception);
        }
    }

    private ExtractedDependencyNode convertProjectRoot(MavenProject project, DependencyNode dependencyRoot) {
        ArtifactCoordinate rootCoordinate = new ArtifactCoordinate(
            project.getGroupId(),
            project.getArtifactId(),
            project.getPackaging() == null ? "jar" : project.getPackaging(),
            "",
            project.getVersion()
        );
        List<ExtractedDependencyNode> children = dependencyRoot.getChildren().stream()
            .map(this::convert)
            .toList();
        return new ExtractedDependencyNode(rootCoordinate, "root", false, children, List.of());
    }

    private ExtractedDependencyNode convert(DependencyNode node) {
        Artifact artifact = node.getArtifact();
        ArtifactCoordinate coordinate = new ArtifactCoordinate(
            artifact.getGroupId(),
            artifact.getArtifactId(),
            artifact.getType(),
            artifact.getClassifier(),
            artifact.getVersion()
        );
        List<ExtractedDependencyNode> children = node.getChildren().stream()
            .map(this::convert)
            .toList();
        return new ExtractedDependencyNode(coordinate, artifact.getScope(), artifact.isOptional(), children, List.of());
    }
}

package dev.gois.tools.depviz;

import dev.gois.tools.depviz.config.DepvizConfig;
import dev.gois.tools.depviz.graph.DependencyGraphExtractor;
import dev.gois.tools.depviz.graph.ExtractedDependencyNode;
import dev.gois.tools.depviz.graph.GraphDocument;
import dev.gois.tools.depviz.graph.GraphDocumentBuilder;
import dev.gois.tools.depviz.graph.MavenDependencyGraphExtractor;
import dev.gois.tools.depviz.graph.ProjectInfo;
import dev.gois.tools.depviz.output.BrowserOpener;
import dev.gois.tools.depviz.output.OutputFiles;
import dev.gois.tools.depviz.output.ViewerWriter;
import java.nio.file.Path;
import org.apache.maven.plugin.AbstractMojo;
import org.apache.maven.plugin.MojoExecutionException;
import org.apache.maven.plugins.annotations.Component;
import org.apache.maven.plugins.annotations.Mojo;
import org.apache.maven.plugins.annotations.Parameter;
import org.apache.maven.project.MavenProject;
import org.apache.maven.shared.dependency.graph.DependencyGraphBuilder;

@Mojo(name = "open", requiresProject = true, threadSafe = true)
public final class OpenMojo extends AbstractMojo {
    @Parameter(defaultValue = "${project}", readonly = true, required = true)
    private MavenProject project;

    @Component
    private DependencyGraphBuilder dependencyGraphBuilder;

    @Parameter(property = "depviz.scope")
    private String scope;

    @Parameter(property = "depviz.open")
    private String open;

    @Parameter(property = "depviz.includes")
    private String includes;

    @Parameter(property = "depviz.excludes")
    private String excludes;

    @Parameter(property = "depviz.layout")
    private String layout;

    @Parameter(property = "depviz.nodeMode")
    private String nodeMode;

    @Parameter(property = "depviz.maxInitialLabels")
    private String maxInitialLabels;

    @Parameter(property = "depviz.outputDirectory", defaultValue = "${project.build.directory}/depviz")
    private Path outputDirectory;

    @Override
    public void execute() throws MojoExecutionException {
        DepvizConfig config = createConfig();
        DependencyGraphExtractor extractor = new MavenDependencyGraphExtractor(dependencyGraphBuilder);
        ExtractedDependencyNode root = extractor.extract(project, config);
        GraphDocument document = new GraphDocumentBuilder().build(root, projectInfo(), config);
        try {
            OutputFiles output = new ViewerWriter().write(document, config.outputDirectory());
            getLog().info("Dependency graph generated:");
            getLog().info("  " + output.htmlFile().toAbsolutePath());
            if (config.open()) {
                boolean opened = new BrowserOpener().open(output.htmlUri());
                if (opened) {
                    getLog().info("Opened in browser.");
                } else {
                    getLog().warn("Browser could not be opened automatically.");
                    getLog().info("Open this URL manually:");
                    getLog().info("  " + output.htmlUri());
                }
            } else {
                getLog().info("Open this URL manually:");
                getLog().info("  " + output.htmlUri());
            }
        } catch (Exception exception) {
            throw new MojoExecutionException("Failed to write dependency graph viewer: " + exception.getMessage(), exception);
        }
    }

    private DepvizConfig createConfig() throws MojoExecutionException {
        try {
            return DepvizConfig.fromRaw(scope, open, includes, layout, nodeMode, maxInitialLabels, excludes, outputDirectory);
        } catch (IllegalArgumentException exception) {
            throw new MojoExecutionException(exception.getMessage(), exception);
        }
    }

    private ProjectInfo projectInfo() {
        return new ProjectInfo(
            project.getGroupId(),
            project.getArtifactId(),
            project.getVersion(),
            project.getPackaging(),
            project.getName(),
            project.getBasedir() == null ? "" : project.getBasedir().getAbsolutePath(),
            !project.getModules().isEmpty(),
            project.getModules()
        );
    }
}

Create `viewer/src/filtering.ts`:

```ts
import type { GraphDocument, GraphNode } from "./types";

export interface ViewerFilterState {
  query: string;
  scope: string;
  optional: "all" | "hide" | "only";
  collapsedEdgeIds: Set<string>;
}

export interface ViewerFilterResult {
  visibleNodeIds: Set<string>;
  visibleEdgeIds: Set<string>;
  matchedNodeIds: Set<string>;
}

export function applyViewerFilters(document: GraphDocument, state: ViewerFilterState): ViewerFilterResult {
  const matchedNodeIds = new Set<string>();
  const visibleNodeIds = new Set<string>();
  const visibleEdgeIds = new Set<string>();
  const normalizedQuery = state.query.trim().toLowerCase();

  for (const node of document.nodes) {
    if (!matchesScope(node, state.scope) || !matchesOptional(node, state.optional)) {
      continue;
    }
    if (normalizedQuery && matchesQuery(node, normalizedQuery)) {
      matchedNodeIds.add(node.id);
    }
    if (!normalizedQuery || matchesQuery(node, normalizedQuery) || node.root) {
      visibleNodeIds.add(node.id);
    }
  }

  for (const edge of document.edges) {
    if (state.collapsedEdgeIds.has(edge.id)) {
      continue;
    }
    if (visibleNodeIds.has(edge.source) && visibleNodeIds.has(edge.target)) {
      visibleEdgeIds.add(edge.id);
    }
  }

  return { visibleNodeIds, visibleEdgeIds, matchedNodeIds };
}

function matchesScope(node: GraphNode, scope: string): boolean {
  return scope === "all" || node.scope === scope || (scope === "root" && node.root);
}

function matchesOptional(node: GraphNode, optional: ViewerFilterState["optional"]): boolean {
  if (optional === "all") {
    return true;
  }
  if (optional === "hide") {
    return !node.optional;
  }
  return node.optional;
}

function matchesQuery(node: GraphNode, query: string): boolean {
  return [
    node.id,
    node.coordinate,
    node.groupId,
    node.artifactId,
    node.version,
    node.scope,
    node.type,
    node.classifier
  ].some((value) => value.toLowerCase().includes(query));
}
```

```md
# Depviz Maven Plugin

Depviz generates a local, offline, interactive Maven dependency graph viewer.

```bash
mvn depviz:open
```

During local development before plugin prefix configuration:

```bash
mvn dev.gois.tools:depviz-maven-plugin:0.1.0-SNAPSHOT:open
```

## Requirements

- Maven 3.9+
- Java 17+

The generated viewer runs from local files. It does not require an IDE, Graphviz, Node.js, a local server, a CDN, or internet access at viewer runtime.

## Local Build

```bash
mvn -q -DskipTests=false install
```

## Usage

Generate and open the runtime dependency graph:

```bash
mvn depviz:open
```

Generate without opening the browser:

```bash
mvn depviz:open -Ddepviz.open=false
```

Use fully qualified plugin coordinates during local development:

```bash
mvn dev.gois.tools:depviz-maven-plugin:0.1.0-SNAPSHOT:open -Ddepviz.open=false
```

Limit to compile dependencies:

```bash
mvn depviz:open -Ddepviz.scope=compile
```

Include Spring dependencies and paths required to reach them:

```bash
mvn depviz:open -Ddepviz.includes=org.springframework:*
```

Exclude common test dependencies:

```bash
mvn depviz:open -Ddepviz.excludes=junit:*,org.junit:*,org.mockito:*
```

Write to a custom output directory:

```bash
mvn depviz:open -Ddepviz.outputDirectory=target/custom-depviz
```

## Output

```text
target/depviz/
  dependency-graph.html
  dependency-graph.json
  assets/
```

Open `target/depviz/dependency-graph.html` in a browser.

## Viewer

The viewer supports pan, zoom, node dragging, search, scope filtering, optional dependency filtering, label visibility control, layout switching, selected node details, path-to-root, neighborhood highlighting, collapse/expand, and diagnostics when Maven exposes diagnostic metadata.

## Troubleshooting

### Browser did not open

The plugin still generates the files. Open the printed `file://` URI manually.

### Dependency resolution failed

Run `mvn dependency:tree` or `mvn test` in the project first. Depviz uses Maven APIs and depends on Maven being able to resolve the project.

### Plugin prefix is not recognized

Use the fully qualified form:

```bash
mvn dev.gois.tools:depviz-maven-plugin:0.1.0-SNAPSHOT:open
```

### Graph is large

Use search, scope filters, collapse/expand, or lower label visibility. The default label threshold is controlled by:

```bash
-Ddepviz.maxInitialLabels=500
```

## Security And Privacy

Dependency data stays local. Depviz does not upload dependency data and the generated viewer does not load CDN assets at runtime.

## Known Limitations

- It visualizes Maven dependency graphs, not Java source/package/class dependencies.
- PNG/SVG export is not part of the first version.
- Some diagnostics depend on what Maven APIs expose for a project.
```
